# QuickBooks Error H202 – Troubleshooting Guide

QuickBooks Error H202 can occur when a workstation cannot communicate with the computer hosting the QuickBooks company file in a multi-user environment.

This repository provides an introduction to the issue and directs users to a detailed troubleshooting guide.

## Common symptoms

- QuickBooks displays Error H202.
- A workstation cannot access the company file in multi-user mode.
- Users experience communication problems with the hosting computer.
- QuickBooks cannot establish the required connection.

## Before troubleshooting

- Confirm that the company file is accessible from the hosting computer.
- Check that the hosting computer is switched on and connected to the network.
- Verify that the workstation and host are on the intended network.
- Back up the company file before making significant changes.
- Consult your IT administrator before changing firewall or network settings.
